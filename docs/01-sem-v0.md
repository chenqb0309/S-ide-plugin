# `.sem` v0 文法（子集）

`.sem` 是**契約語言**，不是自然語言散文。

> **原則：簽章嚴格，body 自由。**
> 契約（名稱、型別、可見性）不得隱式變動；實作描述可以是很自然的工程中文。

這份文法同時被三個地方消費，所以它是三者的唯一真相：

1. **TextMate grammar** — 關鍵字高亮
2. **parser** — 抽簽章與依賴，算 cache key、解析連結
3. **AI System Prompt** — 穩定文法才可能下穩定約束

---

## 定址規則（v0 的關鍵約定）

連結、快取失效、依賴圖三件事都要**唯一定址**。因此 v0 立下三條硬約定：

| # | 約定 | 為什麼 |
|---|---|---|
| 1 | **類別名全域唯一**（一個 workspace 內不可重複） | 讓 `[[類別.方法]]` 只靠 regex 就能解析，不需語意分析 |
| 2 | **禁止多載**（不可同名不同參數） | 否則 `類別.方法` 無法唯一定址 |
| 3 | `unit key = 類別名.方法名` | 連結、cache key、manifest 共用同一個 key |

> 中文類別名本來就長、衝突機率低，所以「全域唯一」不會造成負擔，還讓連結短。
> **違反 1 或 2 時，harness 直接報錯（規格 lint），不進生成。** 這是免費拿到的第一層驗證。

## 類別

```sem
類別 用戶服務 {
    契約 {
        使用 資料庫 _db
    }

    方法 註冊新用戶(字串 email, 字串 密碼): 布林 {
        ...
    }
}
```

`契約` 區宣告**欄位與依賴**。

**這是 unit 邊界能成立的前提：AI 只能「使用」契約裡的東西，不能「發明」。**

> 這條規則是為了消滅一類修不好的錯誤。例：AI 自己寫出 `_db` 卻沒人宣告它 → `CS0103` → 迴圈重寫一百次 body 都修不好，因為 `_db` 是欄位，不在方法 body 裡。詳見 [02-prelude-v0.md](02-prelude-v0.md)。

## 方法

```sem
方法 名稱(型別 參數, ...): 返回型別 {
    <步驟...>
}
```

- 返回型別可省略 → `void`
- **簽章是凍結契約**：改簽章 = 全專案失效事件（見 [S1](S1-incremental.md)）

## 語句（v0 子集）

| 語法 | 意義 | 生成 |
|---|---|---|
| `如果 條件 { }` | 條件分支 | `if` |
| `否則如果 條件 { }` | — | `else if` |
| `否則 { }` | — | `else` |
| `每個 X 於 集合 { }` | 走訪 | `foreach` |
| `重複 N 次 { }` | 固定次數 | `for` |
| `返回 值` | 回傳 | `return` |
| `拋出 錯誤(X)` | 丟例外 | `throw` |
| `嘗試 { } 捕捉 錯誤 { }` | 例外處理 | `try/catch` |
| `[[類別.方法]]` | **引用可跳轉的單元** | 方法呼叫 |
| `使用 X` | 宣告依賴 | 欄位／注入 |
| `步驟 "說明"` | **業務時序鏈**的標記點 | `Telemetry.Step(...)` |

v0 **不做**：`當`（while，可後補）、集合字面值、字串插值、泛型方法的型別參數、`大於`/`小於` 以外的運算式語法。

## 修飾符（基礎設施注入）

**這是「人類寫意圖、機器補機制」的核心。在 `.sem` 裡只是四個中文字，在 C# 裡是完整的執行緒／非同步機制。**

| `.sem` | 生成 |
|---|---|
| `【並行處理】` | `async` / `await` / `Task` |
| `【獨佔鎖定】` | `SemaphoreSlim` 或 `lock` |
| `【非同步】` | `Task<T>` 回傳 |
| `【僅內部】` | `internal` 可見性 |

> **demo 的單一視覺**：規格裡四個中文字 → 生成的 C# 長出 `SemaphoreSlim`。看一眼就懂「基礎設施被隱藏了」。

## 連結語法 `[[類別.方法]]`

- `DocumentLinkProvider` 渲染為可點擊連結
- `Ctrl + 點擊` 跨檔跳轉到目標 `.sem` 的對應行
- **指向不存在的目標 → 當場畫紅線**（`DiagnosticCollection`）

**這讓 `.sem` 不只是文字，而是一張有連結的圖。**

而且**斷鏈偵測是免費的規格 lint** ——在完全沒有底層程式碼的狀態下，靠純文字拓撲抓出規格層的錯誤。

## v0 範例（`samples/棧板堆疊器.sem`，零依賴）

```sem
# 棧板堆疊器.sem

資料 箱規格 {
    小數 重量
    整數 長
    整數 寬
    整數 高
}

類別 棧板堆疊器 {
    契約 {
    }

    方法 計算單層箱數(箱規格 規格): 整數 {
        步驟 "判斷重量級距"
        如果 規格.重量 大於 15 {
            返回 4
        }
        返回 8
    }

    方法 計算可堆疊層數(箱規格 規格, 整數 棧板高度): 整數 {
        步驟 "計算層數"
        返回 棧板高度 除以 規格.高
    }
}
```

這個例子**零外部依賴、零資料庫**，一分鐘能講完，是 S0 的預設樣本。
