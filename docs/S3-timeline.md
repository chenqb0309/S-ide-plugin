> ⚠️ **本文的規劃已部分變更：**

> 連結語法亦已由 `[[...]]` 改為反引號。

## 目標

**當語法不可見時，讓行為可見。**

這是整個設計裡唯一補上「隱藏程式碼」這個代價的機制。S0 已經注入 `Telemetry`，本階段把它變成畫面上的東西。

## 一、時序鏈注入

prompt 規則：**每個 `步驟 "說明"` 前面插入 `Telemetry.Step("說明")`**。

> **狀態**：prompt 規則已寫入（`src/core/translate.ts` 第 5 條），
> 但**尚未以真實模型驗證**——MOCK 模式的罐頭回應裡有人手寫的 `Telemetry.Step`，
> 所以「管線能處理」已被證明，「模型會照做」還沒有。

`.sem` 裡：

```sem
方法 計算單層箱數(箱規格 規格): 整數 {
    步驟 "判斷重量級距"
    如果 規格.重量 大於 15 {
        返回 4
    }
    返回 8
}
```

生成的 C# 裡：

```csharp
Telemetry.Step("判斷重量級距");
if (規格.重量 > 15m) { return 4; }
```

執行後輸出：

```
[10:00] 進入 棧板堆疊器.計算單層箱數
[10:00] 步驟1 判斷重量級距
[10:01] 完成 → 4
```

**這一拍對非工程師最有效，因為「AI 自己發現錯、自己修」的迴圈他們未必看得懂，但「流程一步一步跑過去」人人都看得懂。**

## 二、執行與串流

| 步驟 | 做法 |
|---|---|
| 執行 | `spawn('dotnet', ['run', '--project', backendPath])` |
| 輸出 | 串流回外掛 |
| 呈現 | 先丟 `OutputChannel`；若要做終端機感，用 `window.createTerminal()` |

> **`dotnet run` 每次都要編譯，啟動 1~3 秒。**
> 若要「秒回」，改成 build 一次後 `dotnet exec bin/Release/net10.0/backend.dll`。

---

## 三、全刪重生

一個命令：刪掉整個 `Generated/` → 重新生成 → 編譯 → 執行。

**這是 demo 的 money shot，是「C# 是可拋棄產物」唯一的直接證據。**

必須做到：刪完之後，不靠任何人工補救能完全重建。

## 四、SQLite 樣本（Prelude 資料存取點）

| 項目 | 內容 |
|---|---|
| 套件 | `Microsoft.Data.Sqlite`（版本以 `dotnet add package` 決定並寫回 [02-prelude-v0.md](02-prelude-v0.md)） |
| 介面 | `資料庫`（`查詢用戶` / `新增用戶`） |
| 連線 | **Prelude 自己持有**，AI 不需要做 DI |

`.sem` 只寫：

```sem
類別 用戶服務 {
    契約 {
        使用 資料庫 _db
    }
    ...
}
```

AI 直接用 `_db.查詢用戶(...)`，不知道連線怎麼來的。

> **這解決了 v0 最大的風險。** 原本「AI 會發明不存在的套件與欄位」是必炸的坑，現在由 Prelude 從源頭消除：
> 套件是釘死的、欄位是宣告在 `契約` 裡的、AI 只能使用不能發明。

## ⚠️ 修飾符：機制的一半在 harness，不在 prompt

原本以為 `【獨佔鎖定】` → `SemaphoreSlim` 只是 prompt 的一條規則。**不是。**

鎖物件必須是一個**欄位**，否則 AI 只能在方法內 `new SemaphoreSlim(1,1)`——
每次呼叫都拿一把新鎖，**完全沒有互斥效果**。而欄位落在 `契約` 區，屬於 harness 的職責。

所以修飾符的正確實作是：

| 層 | 要做的事 |
|---|---|
| harness | 從修飾符推導出**欄位宣告**，寫進 `<類別>.Fields.g.cs` |
| harness | 對 `【並行處理】` 決定方法簽章要不要 `async`（簽章是 harness 生成的） |
| prompt | 最後才輪到「在 body 裡使用那個欄位」 |

**這推翻了「四個中文字 → 完整機制」的想像。** 詳見 [S2-shell.md](S2-shell.md)。

反過來說，這也正是本專案的價值所在：那些機制之所以能被隱藏，是因為 harness 把欄位、簽章、鎖物件都準備好了，而不是因為 AI 很聰明。

---

## 驗收

1. 執行後畫面上出現**完整的業務時序鏈**
2. **執行期出錯時，時序鏈能指出是哪一個步驟**（而不是丟一個 C# 堆疊）
3. 全刪 `Generated/` → 一鍵完全重建並執行成功
4. SQLite 樣本可寫入並查回資料
5. `【獨佔鎖定】` 生成的 C# 出現 `SemaphoreSlim`，**而且該鎖是欄位**（非區域變數）
